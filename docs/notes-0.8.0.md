Выпуск объединяет два этапа: исправления доменной маршрутизации и DNS по аудиту 0.7.3 и автоматическое обновление программы 0.8.0.

## Обновление программы (новое)

Программа сама узнаёт о новых выпусках здесь, на GitHub, заранее скачивает установщик и предлагает его поставить.

- Раз в сутки служба забирает манифест выпуска и **проверяет его подпись** ключом проекта (ECDSA P-256; открытый ключ зашит в программу). Манифест с неверной подписью отбрасывается целиком.
- Установщик скачивается в `%ProgramData%\SplitVpn\update` — каталог доступен только системе и администраторам. Загрузка идёт с докачкой: обрыв связи не начинает её заново. SHA-256 сверяется после загрузки и ещё раз перед установкой.
- **Установка — только по вашей команде:** «О программе» → «Установить и перезапустить». Windows спросит права администратора, интерфейс закроется, установщик заменит файлы и запустит службу. Сама она не запускается никогда: перезапуск службы прерывает разрешение имён и закрывает сеанс Cisco AnyConnect.
- Фильтры, маршруты и соединение VPN установку переживают — защита при обрыве не снимается.
- Если GitHub недоступен, манифест берётся с зеркал (jsDelivr, raw.githubusercontent) и из адресов в настройках. Зеркалу доверять не нужно: контрольная сумма приходит из подписанного манифеста.
- Настройки — «Настройки» → «Обновление программы»: автопроверка, загрузка заранее, срок. «Пропустить версию» убирает предложение до следующей.
- Из командной строки: `splitvpn-cli update status | check | download | install | skip`.

Интерфейс после обновления сам не открывается: откройте «Раздельный VPN» из меню «Пуск». При включённом автозапуске он вернётся при следующем входе в Windows.

## Доменная маршрутизация и DNS (исправления аудита)

- Закрепления доменных правил перенесены в скомпилированную политику: маршруты, фильтры и диагностика видят одно решение. Адреса сервера VPN, DNS службы, loopback, сети адаптера и служебные адреса туннеля закреплению не подлежат.
- Адрес, назначенный в туннель, выпускается только через его интерфейс; пока туннель или вся группа не подняты — не выпускается вовсе.
- Закрепление помнит суффикс своего правила и снимается, когда правило исчезло или сменило цель. Правило с недоступной целью не разрешается ни через общий DNS, ни из кеша.
- Ключ кеша включает путь разрешения; смена настроек сбрасывает кеш посредника, ответ прежней конфигурации в новый не попадает. Аварийные записи живут не дольше суток и только в режиме «нет сети».
- Общая проверка ответов upstream для UDP и TCP; адреса берутся только из цепочки CNAME своего имени.
- DNS-посредник ограничивает одновременные запросы и соединения TCP, ставит общий дедлайн обслуживания и объединяет одинаковые запросы в полёте.
- Команды помощнику AnyConnect уходят через ограниченную очередь с отдельным писателем: зависшая запись завершает процесс по своему дедлайну.

## Состав

Служба Windows, интерфейс WPF и трей, помощник AnyConnect. Протоколы: SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect (дополнительным подключением, вход через SSO во встроенном браузере). Защита при обрыве на WFP, DNS-посредник, автообновляемые списки адресов (RU-база и список обхода блокировок), правила по подсетям и доменам, группы подключений.

Требуется Windows 11 x64; .NET 10 входит в поставку.

## Установка

Первая установка и установка поверх — одинаково:

```
msiexec /i SplitVpn-0.8.0.msi
```

Перед установкой поверх закройте «Раздельный VPN»: установщик заменяет его файлы. Начиная с этой версии он закрывает приложение сам, но если оно свёрнуто в трей, надёжнее выйти через меню значка.

Обновление с 0.7.x ставится вручную: прежние версии про автообновление ещё не знают. Дальше программа будет предлагать обновления сама.
