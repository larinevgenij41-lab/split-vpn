Исправлена настоящая причина сброса Wi-Fi после включения компьютера и после переподключения Wi-Fi.

## Запуск Windows и Wi-Fi

- **Проверка интернета Windows больше не получает отказ.** Windows проверяет интернет по адресу www.msftconnecttest.com. Программа открывала к нему не больше 4 адресов и заранее держала 2-4 из них целый час. Сеть доставки Microsoft отвечает каждый раз другими адресами, поэтому уже второй ответ не помещался в предел. Тогда DNS программы отвечал Windows отказом, она считала Wi-Fi сетью "без интернета" и через полминуты сбрасывала его вместе с VPN. Исправления 0.15.9 и 0.15.16 этого не касались, поэтому не помогли.
- Адреса, открытые заранее, никому не выданы, и теперь ответ самой Windows их заменяет. Адреса, уже выданные Windows, сохраняются до конца срока ответа. Новый заранее полученный набор заменяет прежний, а не копится. Предел поднят до 8 адресов.
- **Отказ виден в журнале.** Если ответ на проверку интернета Windows всё-таки отклонён, служба пишет предупреждение с причиной (не чаще раза в минуту). Раньше такой отказ не попадал в журнал службы.

## Состав и установка

Служба Windows, интерфейс WPF и трей, помощник AnyConnect. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect. Требуется Windows 11 x64; .NET 10 входит в поставку.

Перед обновлением закройте "Раздельный VPN", в том числе через меню значка в трее. Установщик обновляет интерфейс и службу вместе, сохраняя настройки и подключения:

```
msiexec /i SplitVpn-0.15.18.msi
```
