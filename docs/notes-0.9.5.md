Исправлены ошибки DNS и выбора маршрутов при нескольких VPN, доменных исключениях и частичных сбоях. Разрешение адресов VPN-серверов больше не задерживает команды подключения и отключения. Обновление DNS сохраняет действующее VPN-соединение, а восстановление маршрутов и фильтров корректно завершает прерванное применение.

## Исправления

- Просроченный DNS-ответ выдаётся только после подтверждения нужного маршрута; срок кеширования не превышает срок доменного закрепления.
- При временной ошибке DNS-сервера используется следующий сервер из списка.
- Начальное разрешение VPN-серверов выполняется в фоне с ограничением параллелизма и отменой при отключении. Неудачный запрос первого профиля не останавливает очередь остальных.
- Адресные назначения защищены от выхода через чужой VPN. Доменное исключение корректно перекрывает адресное правило, включая отдельный маршрут /32.
- Изменившиеся группы фильтров WFP применяются одной транзакцией. Неполный комплект фильтров восстанавливается, исправные фильтры сохраняются.
- Доменные правила не могут переназначить IP самого DNS-сервера: конфликтующий ответ отклоняется, чтобы сохранить работу DNS.
- Обновление IP VPN-сервера сохраняет маршруты действующего сеанса, в том числе после перезапуска службы.
- После восстановления маршрута снимается прежний отказ доменного закрепления.

## Состав и проверки

Windows x64: служба, интерфейс WPF, DNS-посредник, защита при обрыве, списки адресов и помощник Cisco AnyConnect. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect.

759 автоматических тестов: 470 ядра и 289 службы. Сценарии маршрутизации и отказов проверены на подменённых системных операциях; нативное прохождение пакетов в этом выпуске отдельно не проверялось.

Обработка DNS из кеша и сборка политики сохранили скорость в синтетическом замере. Дополнительная защита направлений увеличила построение большого плана фильтров с 8,6 до 34,2 мс; нативные фильтры обновляются разностно. Это замер внутренних операций, а не пропускной способности VPN.

## Установка

Перед установкой поверх закройте «Раздельный VPN» (`SplitVpn.exe`), затем выполните:

```powershell
msiexec /i SplitVpn-0.9.5.msi
```

Версии начиная с 0.9.1 могут получить выпуск через «О программе» → «Обновление». Для более ранних версий нужна ручная установка: они ещё не знают действующий ключ подписи обновлений.
