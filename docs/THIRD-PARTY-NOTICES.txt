Раздельный VPN — сторонние данные и компоненты

Собственный код проекта распространяется по лицензии MIT (файл LICENSE в корне репозитория).
Перечисленные ниже компоненты остаются под своими лицензиями. Библиотеки LGPL подключаются
динамически отдельными DLL и заменяемы: собрать и подставить свою сборку можно без изменения
остального кода (scripts/build-openconnect.sh). Списки адресов (RU-база и список обхода
блокировок) в поставку не входят — их скачивает сама программа по выбору пользователя,
условия их использования — у поставщиков списков.

------------------------------------
Loyalsoldier/geoip — https://github.com/Loyalsoldier/geoip
  Файл text/ru.txt формируется из GeoLite2 Country (MaxMind).
  GeoLite2: This product includes GeoLite2 data created by MaxMind, available from https://www.maxmind.com.
  Лицензия данных GeoLite2: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
  Код Loyalsoldier/geoip: MIT.
ipverse/rir-ip — https://github.com/ipverse/rir-ip
  Списки по стране регистрации из данных региональных регистраторов (RIR). Данные RIR — по условиям регистраторов;
  формат агрегирования ipverse — MIT.
