Исправлен сброс Wi-Fi после включения компьютера и после переподключения Wi-Fi. Исправление из 0.15.9 срабатывало не всегда: с 11 по 14 ноября Windows сбрасывала Wi-Fi при 4 загрузках из 6.

## Запуск Windows и Wi-Fi

- **Адрес проверки интернета Windows открывается до дозвона.** Когда Wi-Fi только подключился, программа сразу начинала готовить подключение VPN. При запуске Windows на это уходит больше 2 секунд, и всё это время запрос Windows на проверку интернета ждал своей очереди, а потом получал отказ. Windows считала сеть "без интернета" и через полминуты сбрасывала Wi-Fi, а вместе с ним и только что поднятый VPN. Теперь программа сначала открывает адрес проверки (обычно за доли секунды, не дольше 2 секунд), а потом начинает дозвон.
- **Запрос проверки ждёт дольше.** Если программа всё же занята, ответ на запрос проверки интернета Windows ждёт до 8 секунд вместо 2. Для остальных адресов ожидание не изменилось.
- **Это видно в журнале.** Служба пишет, когда открыла адрес проверки заранее. Если запрос проверки всё-таки получил отказ, в журнале появляется предупреждение: раньше причину сброса Wi-Fi приходилось искать по журналам Windows.

## Состав и установка

Служба Windows, интерфейс WPF и трей, помощник AnyConnect. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect. Требуется Windows 11 x64; .NET 10 входит в поставку.

Перед обновлением закройте "Раздельный VPN", в том числе через меню значка в трее. Установщик обновляет интерфейс и службу вместе, сохраняя настройки и подключения:

```
msiexec /i SplitVpn-0.15.16.msi
```
