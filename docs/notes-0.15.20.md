## Запуск Windows и Wi-Fi

- **Ответ на проверку интернета Windows не ждёт чужих адресов.** Если адрес www.msftconnecttest.com уже открыт, ответ уходит сразу. Раньше он ждал, пока служба применит адреса других программ, и при занятой службе Windows получала отказ, после чего сбрасывала Wi-Fi.
- **Подъём VPN больше не отклоняет ответы DNS, которые он не затрагивает.** Раньше любое изменение настроек DNS-посредника отклоняло все ответы, которые были в работе, в том числе ответ на проверку интернета Windows.
- Если новый адрес проверки интернета не удалось открыть вовремя, Windows получает адреса, которые уже открыты, а не отказ.
- **Автоподключение не отключается на всю загрузку**, если Windows при запуске временно не может прочитать сохранённый пароль или ключ IPsec. Служба повторяет попытку две минуты и только потом просит ввести пароль.

## Подключения

- **Чужое подключение Windows к тому же серверу разрывается, только когда служба сама держит или поднимает своё.** Раньше оно разрывалось и тогда, когда своё подключение ждало пароль, вход или было отключено через меню сети Windows.
- При двух подключениях к одному серверу решение о разрыве чужого подключения принимается по тому, которое служба держит.
- Зависшая проверка конфликтов через минуту считается сорванной: следующая запускается, только когда прежняя завершится, и устаревшая проверка не разрывает чужие подключения. Раньше проверка останавливалась до перезапуска службы.
- Сеанс, оборвавшийся сразу после дозвона, закрывается, а повтор идёт с растущей паузой. Раньше служба дозванивалась без пауз. Временный сбой чтения сетевых таблиц сразу после дозвона живой сеанс не рвёт: служба сразу повторяет привязку до двух раз.
- После собственного разрыва и после отключения пользователем служба не ждёт три минуты на сеансе без связи.
- При подъёме по очереди подключение с нечитаемым ключом IPsec не задерживает остальные.
- Подключение, поставленное на паузу, не подхватывает сеанс, поднятый для него средствами Windows: такой сеанс разрывается.
- AnyConnect: узел шлюза с меняющимися адресами получает уже открытые адреса, переподключение не срывается.
- AnyConnect: при сбое настройки интерфейса после создания адаптера сеанс на шлюзе закрывается, место для одновременного входа не остаётся занятым.
- AnyConnect: помощник не удаляет из хранилища системной учётной записи чужие сертификаты с тем же ключом. Если вход после этого не удался, сообщение об ошибке называет такие сертификаты.

## DNS

- **Имя сервера VPN с кириллицей** (например, vpn.пример.рф) находится в закреплённых ответах: подключение восстанавливается и при заблокированном трафике.
- **Псевдоним не обходит правило "Блокировать".** Если имя без правила ведёт (CNAME) в домен с вашим правилом "Блокировать", ответ отклоняется. На правила туннеля это не распространяется: адреса из ответа постороннего DNS за туннелем не закрепляются.
- Ответ, полученный в прежней сети, не попадает в кеш после смены сети.

## Настройки и пароли

- **Недопустимое значение в файле настроек не останавливает службу.** При загрузке такие значения заменяются на значения по умолчанию, исходный файл сохраняется рядом, исправленный записывается на его место, в журнале появляется предупреждение.
- Сбой разрыва или шифрования пароля при смене данных входа не оставляет подключение на адресах прежнего сервера.
- Пароль или ключ IPsec, который Windows временно не может прочитать, не удаляется при сохранении настроек. Если Windows не может прочитать пароль дольше пяти минут подряд, он больше не запрещает сохранять и удалять профиль: он удаляется с предупреждением в журнале.
- Программа не предлагает использовать прежний пароль или ключ IPsec, которого у подключения не было, а просит ввести его. Смена сервера с сохранением прежнего ключа IPsec не требует вводить пароль, если пароль не был сохранён.
- Подключение не остаётся "не сохранено" после смены способа входа с набранным паролем или ключом.
- Выключение "сохранять пароль" удаляет пароль из файла, даже если Windows в этот момент не может его прочитать.
- После смены пароля прежний не остаётся в побочных копиях файла паролей.
- Новое подключение, записанное службой до сбоя сохранения пароля, удаляется кнопкой "Удалить" и из службы.
- Блок "Параметры входа и безопасности" раскрывается для подключений, которым он нужен, и после ручного сворачивания.
- Журнал событий на странице диагностики перечитывается целиком после потери связи со службой.
- Командная строка: `profile set` для существующего подключения не включает сохранение пароля без явного флага. Добавлен флаг `--save-password`.

## Обновление программы

- После ручной установки промежуточной версии программа снова предлагает новый выпуск.
- Установщик, завершившийся в первые секунды после запуска, не показывается как сбой с просьбой перезагрузить компьютер: через несколько минут обновление можно запустить заново. Настоящий сбой установки по-прежнему показывается с именем журнала установки.

## Состав и установка

Служба Windows, интерфейс WPF и трей, помощник AnyConnect. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect. Требуется Windows 11 x64; .NET 10 входит в поставку.

Перед обновлением закройте "Раздельный VPN", в том числе через меню значка в трее. Установщик обновляет интерфейс и службу вместе, сохраняя настройки и подключения:

```
msiexec /i SplitVpn-0.15.20.msi
```
