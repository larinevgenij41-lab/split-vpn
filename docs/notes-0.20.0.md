Выпуск стабильности: исправлено около сотни ошибок, найденных двумя кругами проверки кода. Главное: закрыта утечка трафика мимо VPN через сети выключенного доверенного адаптера, долгие соединения к сайтам с правилами для доменов больше не обрываются, «Отключить» работает во время дозвона, Cisco AnyConnect замечает зависший сеанс, окно входа SSO не даёт продолжить при ошибке сертификата. Новых возможностей нет.

Изменения проверены автоматическими тестами (их стало 3460 вместо 2675). На настоящем компьютере с работающим VPN этот выпуск перед публикацией не проверялся.

## Защита

- **Сети доверенного адаптера не открываются через другие адаптеры.** Если доверенный адаптер (Radmin VPN, ZeroTier и подобные) выключен, а VPN оборвался, трафик на публичные адреса его сети раньше уходил через основной адаптер мимо защиты. Теперь такие адреса пропускаются только через сам доверенный адаптер.
- **Собственные маршруты программы** на адаптере, который отметили доверенным, больше не считаются его локальной сетью и не перекрывают ваши правила, включая «Блокировать».
- **Окно входа Cisco AnyConnect (SSO):** при ошибке сертификата страница не открывается и продолжить нельзя; загрузки файлов и запросы разрешений (камера, геолокация и другие) отклоняются; части страницы, открываемые без HTTPS, не загружаются.
- **Адрес шлюза AnyConnect в нестрогой записи IPv4** («010.0.0.1», «10.1») больше не принимается: раньше он молча превращался в другой адрес. Если такой адрес уже сохранён, подключение не поднимается и просит исправить адрес.
- **Запуск второго экземпляра службы** из консоли больше невозможен: раньше он перехватывал связь с приложением и обрывал туннели «VPN поверх SSH» работающей службы.
- **Системные библиотеки** загружаются только из каталога Windows.

## Подключения

- **«Отключить» и «Отключить и восстановить интернет»** доступны всегда, в том числе пока другая команда ждёт конца дозвона (раньше — до полутора минут ожидания).
- **Сбой одного подключения не мешает остальным.** Неожиданная ошибка при подъёме одного туннеля раньше останавливала подъём всех следующих.
- **Cisco AnyConnect:** если помощник перестал отвечать, сеанс завершается через 20 секунд и программа просит войти снова; раньше «Подключено» могло показываться бесконечно. При выключении Windows программа сразу прощается со шлюзом, чтобы сеанс на нём не повисал.
- **VPN поверх SSH:** несовместимые алгоритмы шифрования или обмена ключами — понятная ошибка вместо бесконечных повторов; работают серверы с ключом RSA до 16384 бит.
- **Разрыв подключений SSTP/L2TP/IKEv2/PPTP** больше не задерживает остальную работу службы на время до 15 секунд на туннель.
- **После сна** туннели перепроверяются сразу, а не через минуту.
- **Подъём по очереди** не зависает, когда служба удалённого доступа Windows ещё не отвечает.
- **IKEv2:** настройка шифрования пишется в то место телефонной книги, куда её пишет сама Windows.

## Правила для доменов

- **Долгие соединения не обрываются.** Раньше маршрут к адресу сайта снимался по истечении срока DNS-записи (от минуты до часа), и загрузки, видео и постоянные соединения зависали. Теперь маршрут держится, пока к адресу есть соединение: до 24 часов, а если правило выводит адрес из VPN или из-под блокировки — не дольше часа. Потоки UDP/QUIC (HTTP/3) держатся 5 минут после срока записи.
- **Пределы:** из одного ответа DNS закрепляется не больше 16 адресов, на одно правило — не больше 2000. Раньше одно правило на крупную сеть доставки могло исчерпать общий предел и остановить разрешение имён для всех правил.
- **Один недопустимый адрес** в ответе больше не отклоняет весь ответ: остальные адреса работают.
- **Правило на публичную зону** («co.uk», «com.ru») больше нельзя создать: оно охватывало бы чужие сайты. Ведомственные зоны («gov.ru», «edu.ru») допустимы.

## Приложение

- **Сбой при запуске** больше не оставляет невидимый процесс, из-за которого окно не открывалось до выхода из Windows.
- **Системный прокси шлюза** снимается и при аварийном завершении приложения, и при выходе из Windows.
- **Уведомления** не идут шквалом при мигающем соединении.
- **Обновление:** кнопка называется «Установить» — приложение после установки нужно открыть заново; после отказа в окне контроля учётных записей установку можно повторить сразу; зависший установщик не блокирует обновления навсегда.
- **Диагностика:** сбор архива не блокируется зависшей системной службой и укладывается в предел размера.
- Окно больше не замирает при удалении подключения AnyConnect и при переключении темы.

## Служба

- Не падает в цикле, если при переходе со старых настроек не удалось записать их копию.
- Причина аварийного завершения пишется в журнал службы.
- Соединения с приложением не исчерпываются при нескольких сеансах пользователей.
- При неполном возврате сети во время удаления программы скрипт восстановления и инструкция остаются в `%ProgramData%\SplitVpn.Uninstall`.

## На что обратить внимание

- **Изменилось поведение:**
  - маршрут к адресу под правилом для домена живёт дольше срока DNS-записи, пока есть соединения; на это время правило действует для всех программ и сайтов с тем же адресом;
  - сеанс Cisco AnyConnect завершается, если помощник молчит 20 секунд;
  - повтор одного и того же уведомления подавляется в течение минуты;
  - новое правило на публичную зону, больше 8 контрольных целей, больше 64 подключений отклоняются при сохранении; уже сохранённые настройки продолжают работать;
  - служба запускается только через диспетчер служб Windows (для разработки — ключ `--console`).
- Ограничения и подробности — в `docs/LIMITATIONS.md`.

В поставку входят служба Windows, графическое приложение, помощник OpenConnect и движок SSH. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP, Cisco AnyConnect и VPN поверх SSH (TCP).

Перед установкой поверх прежней версии закройте SplitVpn.exe. Во время обновления служба перезапустится. Команда установки

```powershell
msiexec /i SplitVpn-0.20.0.msi
```
