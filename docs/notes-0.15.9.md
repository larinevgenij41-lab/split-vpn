Исправления по разбору сбоя при запуске Windows. После включения компьютера Windows примерно через 30 секунд сама сбрасывала Wi-Fi, считая сеть "без интернета": её проверка интернета упиралась в защиту, пока VPN ещё поднимался. Сброс обрывал только что поднятый VPN, а сервер ещё пару минут держал оборванный сеанс, и интернета не было 2-3 минуты.

## Запуск Windows и Wi-Fi

- **Проверка интернета Windows идёт напрямую.** Windows проверяет интернет по адресам Microsoft (www.msftconnecttest.com и dns.msftncsi.com). Теперь эти имена разрешаются через DNS провайдера, а к адресу проверки открыт только порт 80 через основной адаптер. Windows видит интернет сразу после подключения Wi-Fi и больше не сбрасывает адаптер. Провайдер видит эти проверки, как и без VPN. Если нужно вести их через VPN, добавьте правило для домена msftconnecttest.com.
- **Wi-Fi, который ещё подключается, не называется "не найденным".** При запуске Windows и переподключении Wi-Fi вместо ошибки "Закреплённый основной адаптер не найден (например, после сброса сети Windows)" показывается "Ждём подключения закреплённого адаптера", а в журнале это сведения, а не ошибка. VPN поднимается сам, когда Wi-Fi подключится.

## Подключение

- **После обрыва сеанс не рвётся по кругу.** Если соединение оборвалось не по команде программы (пропал Wi-Fi, оборвалась сеть), сервер этого не видит и ещё до 2-3 минут держит прежний сеанс. Новый сеанс с тем же адресом в это время трафик не пропускает. Раньше программа каждые 20 секунд разрывала его и подключалась заново, что не помогало. Теперь она ждёт до 3 минут на том же сеансе и пишет об этом в журнал. Трафик пойдёт, как только сервер отпустит старый сеанс.
- **Окно входа AnyConnect повторяет загрузку само.** Если страница входа организации не открылась из-за сетевой ошибки (например, имя не найдено, пока VPN поднимается), окно повторяет загрузку до 6 раз через 5 секунд. Закрывать окно и входить заново больше не нужно.

## Состав и установка

Служба Windows, интерфейс WPF и трей, помощник AnyConnect. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP и Cisco AnyConnect. Требуется Windows 11 x64; .NET 10 входит в поставку.

Перед обновлением закройте "Раздельный VPN", в том числе через меню значка в трее. Установщик обновляет интерфейс и службу вместе, сохраняя настройки и подключения:

```
msiexec /i SplitVpn-0.15.9.msi
```
