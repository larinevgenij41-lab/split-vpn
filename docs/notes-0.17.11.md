Исправлена вероятная причина перезапуска адаптера Wi-Fi после загрузки Windows. На части компьютеров Windows через 16 секунд после подключения Wi-Fi повторяла проверку безопасности, ещё через 16 перезапускала драйвер адаптера (событие 4003 в журнале "Система"), а через минуту отключала Wi-Fi ещё на минуту. Все подключения VPN при этом рвались. Запись загрузки показала: Windows начинает проверку интернета через сотую долю секунды после появления сети, а программа открывала для неё путь на полсекунды позже, и DNS-посредник в этот промежуток отвечал отказом сразу. Такой отказ Windows не повторяет: через 5 секунд она считает сеть "только локальной" и запускает восстановление адаптера.

Теперь DNS-посредник на запрос имён проверки интернета Windows (`www.msftconnecttest.com`, `dns.msftncsi.com`, `ipv6.msftconnecttest.com`) не отвечает отказом, пока путь не готов: он ждёт новых настроек до 4 секунд и отвечает уже по ним. Остальных имён это не касается.

Программа также сама переживает перезапуск адаптера, если он всё же случится, и записывает его ход.

Новые подключения VPN теперь ждут 20 секунд после подключения Wi-Fi. Если за это время Windows начала восстановление, они ждут его конца и поднимаются один раз, а не строятся на 9-й секунде, чтобы оборваться на 32-й. Защита и DNS включаются сразу, как раньше: пока подключения ждут, трафик идёт по правилам обрыва. Ожидание ограничено тремя минутами от первого подключения Wi-Fi: если Windows перезапускает адаптер по кругу, VPN поднимается, не дожидаясь конца. Уже поднятые подключения и подключение по кабелю это не затрагивает.

Служба ведёт запись подключения Wi-Fi: события Windows (подключение, повторная проверка безопасности, перезапуск адаптера, отключение) и собственные действия, которые что-то изменили (фильтры защиты, маршруты, DNS адаптера, подъём туннелей), в одной шкале времени. Как только Windows начала восстановление, запись сохраняется в файл `wifi-incident-*.log` в каталоге журналов службы и пополняется ещё четыре минуты. Хранится двадцать последних записей, они входят в архив для разбора. В журнале событий программы появляется предупреждение с именем файла.

В поставку входят служба Windows, графическое приложение, помощник OpenConnect и движок SSH. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP, Cisco AnyConnect и VPN поверх SSH (TCP).

Перед установкой поверх прежней версии закройте SplitVpn.exe. Во время обновления служба перезапустится. Команда установки

```powershell
msiexec /i SplitVpn-0.17.11.msi
```
