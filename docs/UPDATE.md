# Обновление программы

С версии 0.8.0 «Раздельный VPN» сам узнаёт о новых выпусках на GitHub, заранее скачивает установщик
и предлагает его поставить. Устройство то же, что у автообновляемых списков адресов: проверка по
расписанию, отказ от фоновой работы в лимитной сети и выход в сеть только тогда, когда его допускает
защита.

## Что происходит

1. **Проверка.** Раз в сутки (срок настраивается) служба забирает манифест последнего выпуска —
   килобайтный файл `update.json` со списком: версия, имя установщика, его размер и SHA-256.
2. **Проверка подписи.** Манифест подписан ключом проекта; открытый ключ зашит в программу. Манифест
   с неверной подписью отбрасывается целиком, и ничего не скачивается.
3. **Загрузка.** Если версия новее установленной, служба качает установщик в
   `%ProgramData%\SplitVpn\update` — каталог доступен только системе и администраторам, поэтому
   подменить проверенный пакет нельзя. Загрузка идёт с докачкой: обрыв связи не начинает её заново.
4. **Сверка.** SHA-256 скачанного сверяется с манифестом, и ещё раз — прямо перед установкой.
5. **Установка — только по вашей команде.** «О программе» → «Установить и перезапустить». Windows
   спросит права администратора, интерфейс закроется, установщик заменит файлы и запустит службу.

Установка никогда не запускается сама: она перезапускает службу и закрывает интерфейс, и решать,
когда это уместно, должен человек.

## Что происходит с VPN во время установки

Фильтры WFP, маршруты и соединение RAS переживают перезапуск службы — защита при обрыве не
снимается, трафик мимо туннеля не уходит. Прерывается разрешение имён: DNS-посредник живёт в
процессе службы, и на несколько десятков секунд имена перестают разрешаться. Сеанс Cisco AnyConnect
перезапуск не переносит — после обновления в шлюз придётся войти заново; программа предупреждает об
этом в окне подтверждения.

Интерфейс после обновления сам не открывается: откройте «Раздельный VPN» из меню «Пуск». При
включённом автозапуске он вернётся при следующем входе в Windows.

## Настройки

«Настройки» → «Обновление программы»:

- **Проверять обновления автоматически** — выключает плановые проверки; кнопка «Проверить» в
  «О программе» остаётся.
- **Скачивать обновление заранее** — выключает фоновую загрузку: установщик скачается по кнопке
  «Загрузить».
- **Как часто** — раз в день, раз в три дня или раз в неделю.

«Пропустить версию» убирает предложение до появления следующей; ручная проверка предложит её снова.

## Если GitHub недоступен

Манифест берётся по четырём путям подряд: активы последнего выпуска на `github.com`, затем
`cdn.jsdelivr.net` и `raw.githubusercontent.com` (там он лежит в дереве репозитория), затем адреса
из настроек. Установщик раздаётся только активами выпуска и вашими зеркалами: он весит десятки
мегабайт, и в дерево репозитория его не положить.

Зеркалу доверять не нужно: SHA-256 установщика приходит из подписанного манифеста, поэтому подменить
пакет на зеркале нельзя.

Недоступность GitHub при выключенной защите — обычное дело: программа запишет это в журнал и
повторит через час, предупреждения в шапке не появится.

## Проверка вручную

Скачать установщик со страницы выпусков и запустить `msiexec /i SplitVpn-<версия>.msi` можно
по-прежнему. Перед установкой поверх закройте «Раздельный VPN» и сверьте SHA-256 из заметок к
выпуску: установщик не подписан Authenticode, и Windows покажет «Неизвестный издатель».

Из командной строки: `splitvpn-cli update status | check | download | install | skip`.

Порядок выпуска и ключ подписи — [RELEASE.md](RELEASE.md).
