Подробный журнал на срок и архив для разбора: редкие проблемы (например, при входе в Windows под другим пользователем) теперь можно записать подробно и передать одним файлом.

## Новое

- «Диагностика» → «Подробный журнал»: включается на 1, 4 или 24 часа, переживает перезапуск службы и перезагрузку, выключается сам. Пока он включён, в меню виден значок «Подробный журнал до ЧЧ:ММ».
- В подробном режиме служба пишет, кто подключается к каналу управления (учётная запись, SID, сеанс Windows, процесс, права) и почему ему отказано, команды и их итог, очередь службы, сверку, фильтры WFP, маршруты, DNS адаптеров, дозвон RAS, отладочный журнал Cisco AnyConnect и этапы обновления. Каждый DNS-запрос — отдельной строкой в своём файле.
- Интерфейс каждого пользователя ведёт свой подробный журнал: подключения к службе и отказы, вход через браузер (адреса без параметров), прокси шлюза, автозапуск. Интерфейс, которому служба отказала, узнаёт о режиме из реестра и тоже пишет причину.
- События сеансов Windows (вход, выход, блокировка, подключение по RDP) пишутся в журнал службы всегда.
- «Собрать архив» кладёт на рабочий стол один zip: журналы службы за неделю, журналы интерфейса всех пользователей, адаптеры и маршруты, объекты WFP, состояние, настройки, события службы и журналы событий Windows за трое суток. Пароли, cookie входа и токены в архив не попадают. Если служба отказала, архив собирается из файлов пользователя с объяснением причины.
- Командная строка: `splitvpn-cli diag verbose on --hours N | off | status`, `diag collect [--out <zip>]`.

## Исправления

- Предупреждения DNS-посредника, DNS адаптеров и помощника AnyConnect, которые раньше терялись, попадают в журнал службы.
- Журнал помощника AnyConnect скрывает заголовки `Authorization` и значения, введённые при входе.
- Сбор архива ограничивает чтение растущих файлов и число незавершённых операций; повторные сборы не накапливают зависшие чтения.
- Для готовых архивов установлены пределы количества и объёма, включая ограничение записи до заполнения диска.
- Некорректная дата отдельного файла больше не обрывает сбор: дата заменяется, причина записывается в архив.
- В журналы Windows попадают самые свежие события; при усечении архива это явно отмечается.

## Совместимость

Версия контракта между интерфейсом и службой — 8: обновляйте интерфейс и службу вместе (установщик так и делает).

## Установка

Перед установкой поверх закройте «Раздельный VPN» (`SplitVpn.exe`), затем выполните:

```powershell
msiexec /i SplitVpn-0.10.0.msi
```

Версии начиная с 0.9.1 могут получить выпуск через «О программе» → «Обновление».
