Служба сама отключает в Windows автоматическое переподключение Wi-Fi при "ограниченной связи". На части компьютеров Windows под защитой программы после загрузки считала связь Wi-Fi плохой и восстанавливала адаптер: через 16 секунд после подключения повторяла проверку безопасности, ещё через 16 перезапускала драйвер (событие 4003 в журнале "Система"), а через минуту отключала Wi-Fi ещё на минуту. Все подключения VPN при этом рвались. Исправления 0.17.9 и 0.17.11 это не устранили.

Теперь служба при запуске записывает в реестр значение `EnableBadStateTracking = 0` в разделе `HKLM\SOFTWARE\Microsoft\WcmSvc`. Оно отключает в диспетчере подключений Windows слежение за "плохим состоянием" сети, которое и запускает восстановление адаптера. Это известный обход для VPN-программ с блокировкой трафика.

Настройка начинает действовать после перезагрузки Windows: диспетчер подключений читает её при своём запуске, раньше службы программы. Поэтому после установки этой версии нужна одна перезагрузка. В журнале событий программы появляется запись о том, что настройка изменена.

Прежнее значение служба запоминает и возвращает при удалении программы. Если значение уже было равно нулю, программа его не трогает и при удалении не меняет.

Побочное действие: Windows перестаёт сама переподключать Wi-Fi, когда считает, что в сети нет интернета. На подключение к сети и переход между точками доступа это не влияет.

В поставку входят служба Windows, графическое приложение, помощник OpenConnect и движок SSH. Поддерживаются SSTP, L2TP/IPsec, IKEv2, PPTP, Cisco AnyConnect и VPN поверх SSH (TCP).

Перед установкой поверх прежней версии закройте SplitVpn.exe. Во время обновления служба перезапустится. Команда установки

```powershell
msiexec /i SplitVpn-0.17.12.msi
```
