Новый тип подключения "VPN поверх SSH": туннель через обычное соединение SSH с вашим сервером. Он проходит там, где провайдер обрывает SSTP, WireGuard и другие VPN. Через него идёт только TCP.

## VPN поверх SSH

- **Что это.** Служба запускает программу-движок (sing-box, входит в установщик), которая переносит трафик из своего сетевого адаптера в одно соединение SSH. Правила маршрутизации, DNS и защита работают как для остальных подключений; подключение может быть основным и нести "Остальной интернет".
- **Что нужно.** Сервер с доступом по SSH и разрешённой пересылкой TCP, имя пользователя, открытый ключ сервера и файл закрытого ключа устройства (OpenSSH, без пароля). Подключение создаётся на странице "Подключения".
- **Ключ сервера обязателен.** Сервер сверяется с закреплённым ключом при каждом входе, отключить проверку нельзя.
- **Ключ устройства** хранится в службе зашифрованным, как пароли, и в экспорт подключений не входит.
- **Ограничения.** Только TCP: звонки, игры и QUIC не работают (сайты открываются по TCP), ping не проходит. Весь трафик несёт одно соединение, при потерях в сети замедляется всё сразу. Одновременно включается одно такое подключение. Полный список - docs/LIMITATIONS.md.
- **Защита.** Пока туннель не поднят или оборвался, назначенный ему трафик блокируется. Программе движка открыт только адрес и порт сервера подключения.

## Что учесть

- Установщик стал больше примерно на 7 МБ: в него входит sing-box (GPL-3.0, отдельная программа; условия - в папке licenses\sing-box, архив исходников выложен рядом с установщиком).
- **Откат на 0.15.x.** Прежние версии не читают настройки с подключением "VPN поверх SSH". Перед откатом удалите такие подключения и экспортируйте остальные - порядок в docs/VPN-PROTOCOLS.md.
